# Web Application Security Lab

Учебный проект по информационной безопасности. Разработка веб-приложения на Python с намеренно реализованными уязвимостями SQL Injection и Cross-Site Scripting (XSS), демонстрация их эксплуатации и последующее исправление.

## 1. Цель работы

Изучить основы веб-разработки и принципы безопасности веб-приложений:

- Клиент-серверную архитектуру.
- Протокол HTTP и методы GET/POST.
- Разработку веб-приложений на Flask.
- Работу с базами данных SQLite.
- Механизмы эксплуатации SQL Injection и XSS.
- Методы устранения обнаруженных уязвимостей.

## 2. Используемые технологии

## 4. Установка и запуск

Клонирование репозитория:

```bash
git clone https://github.com/verm1celli/web-security-lab.git
cd web-security-lab
```

Создание виртуального окружения:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установка зависимостей:

```bash
pip install Flask requests
```

Создание базы данных:

```bash
python init_db.py
```

Запуск уязвимой версии:

```bash
python app.py
```

Приложение будет доступно по адресу:

http://127.0.0.1:5000/

Тестовая учётная запись:

- Логин: `admin`
- Пароль: `admin123`

## 5. Реализованные уязвимости

### 5.1. SQL Injection

Уязвимость реализована в обработчике авторизации `/login`.

Причина возникновения: непосредственная подстановка пользовательских данных в SQL-запрос с использованием f-строки Python.

Это позволяет изменить логику SQL-запроса и обойти проверку учётных данных.

Эксплуатация:

```bash
python exploit.py
```

Эксплойт отправляет специально сформированный POST-запрос и демонстрирует возможность обхода авторизации.

### 5.2. Cross-Site Scripting (XSS)

Уязвимость реализована в обработчике поиска `/search`.

Причина возникновения: непосредственная вставка пользовательского ввода в HTML без экранирования.

В результате браузер может интерпретировать переданные данные как исполняемый JavaScript-код.

Эксплуатация:

```bash
python exploit_xss.py
```

Скрипт проверяет отражение внедрённого HTML-кода в HTTP-ответе. Выполнение JavaScript дополнительно демонстрируется в браузере.

## 6. Исправление уязвимостей

Исправленная версия приложения находится в файле `app_correct.py`.

### SQL Injection

Вместо формирования SQL-запроса через f-строку используются параметризованные запросы SQLite.

### XSS

Вместо непосредственного формирования HTML используется шаблонизатор Jinja2 с автоматическим экранированием пользовательских данных.

Запуск исправленной версии:

```bash
python app_correct.py
```

Проверка должна подтвердить, что прежние эксплойты больше не позволяют эксплуатировать обнаруженные уязвимости.

## 7. Файл исправлений

`security_fixes.diff` содержит различия между первоначальной и исправленной версиями приложения.

Он демонстрирует изменения, внесённые для устранения SQL Injection и XSS.

## 8. Ограничения проекта

Проект предназначен исключительно для учебной демонстрации.

В уязвимой версии намеренно используются небезопасные способы обработки пользовательских данных. Пароли тестовых пользователей хранятся в открытом виде для упрощения демонстрации SQL Injection.

Не использовать приложение в производственной среде.
